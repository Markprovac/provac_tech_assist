Première installation — Administrateur

À utiliser une seule fois, avec la clé SETUP_KEY configurée comme secret dans Cloudflare. N'utilise que des données de démonstration tant que Provac n'a pas validé le projet. Cette clé n'est pas enregistrée sur cet appareil.

Après la création du compte, supprime la variable secrète SETUP_KEY de Cloudflare.
